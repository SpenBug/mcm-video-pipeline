## 二、决策树

```
问：内容能不能用「编号 + 一句话」表达？
├─ 能，且总条数 ≤ 10
│   ├─ 是紧迫场景（考前 / 开赛前 / 截止前）→ T2 大字清单档
│   └─ 不是紧迫场景 → T2 也行，但优先看下面
└─ 不能（需要对比、推导、多版式）
    ├─ 主体是「一道真题的完整求解过程」→ T3 真题长拆解档
    ├─ 主体是「论文里的图 / 题目原图」逐张讲 → T4 奶油论文图解档
    ├─ 主体是「赛事资讯」→ T5 赛事资讯快报档
    ├─ 核心是「数字」而不是「句子」→ T8 数据仪表盘档
    ├─ 核心是「一句话主张」而不是一堆信息 → T9 杂志排版档
    ├─ 内容是「规定 / 细则 / 红线」，有官方分量 → T10 黑金权威档
    ├─ 内容像「我记在笔记本上的一页」→ T7 纸感笔记档
    └─ 其余（方法对比 / 对错辨析 / 评分细则 / 自查清单）→ T1 信息密度档
```

**时长校验**：
- < 2 分钟 → T2（其他档撑不到那么短）
- 2–3 分钟 → T5 / T7 / T8 / T9 / T10，或 T1 压到 185s
- 3–4 分钟 → T4
- 4–6 分钟 → T3

**一句话记忆**：
**能不能用「编号 + 一句话」表达？能 → T2；不能 → T1。**
真题 → T3，图讲解 → T4，资讯 → T5，数字 → T8，主张 → T9，规定 → T10，笔记 → T7。

## 四、混搭规则

用户说「T1 的配色 + T5 的版式」这类混搭时，**先确认三件事**：

1. **时长**：以版式多的那档为准（T5 的 10 版式撑不到 120s，会变成 180–200s）
2. **配色来源**：从哪档拿 `theme.ts`，另一档的 accent 语义色要重新映射
   - T1/T5 是 8 色 accent，T2 是 3 档语气，T7/T8/T9/T10 各有固定语义色
   - 映射关系要先写出来给用户看
3. **字幕模式**：混搭时只能选一种（句级 / 整段），不能一个视频里两种并存

**浅色档和深色档不要混**。T4 / T7 / T9 是浅色底，T1 / T2 / T3 / T5 / T8 / T10 是深色底，中途换底色会让观众觉得换了个视频。

混搭后要重新算字数预算，并明确告诉用户「这是第一次跑这个组合，版式间距可能需要一轮微调」。

## 五、新增档的门槛

要加第 11 档模板，必须满足：
1. 有一个**已交付**的真源项目（不能是设计稿）——T7–T10 目前是例外，已在文件里明确标注状态
2. 实测时长 / 帧数 / 场景数齐全
3. 能说清「和已有档的差异是什么」——差异小于 30% 就别开新档，做成已有档的变体

新档写完后，回到 `SKILL.md` 的模板索引表加一行。

## 六、`templates/code/` 说明

放 T7–T10 的**可运行 Remotion 组件源码**，每个文件是一个完整的 `React.FC`，直接拷进工程的 `src/remotion/` 并在 `Root.tsx` 注册即可：

```tsx
<Composition id="T7PaperNote" component={T7PaperNote} durationInFrames={150} fps={30} width={1920} height={1080} />
```

⚠️ 这四个组件是**单版式演示**——展示一套风格的一个页面长什么样，不是完整视频组件。要用到实际一期，需要把它们改造成「读 `timing.json` + 按场景切换」的形态，参考 `EpisodeVideo.tsx` 的做法。

复用前先跑一遍 `references/gotchas.md` 第 19 / 20 条的自查（`AbsoluteFill` 的 `width/height:100%` 陷阱），这两条在 T7–T10 的首轮渲染里让 4 张图踩了 3 张。
