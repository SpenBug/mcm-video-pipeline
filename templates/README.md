## 一、决策树

```
问：内容能不能用「编号 + 一句话」表达？
├─ 能，且总条数 ≤ 10
│   ├─ 是紧迫场景（考前 / 开赛前 / 截止前）→ T2 大字清单档
│   └─ 不是紧迫场景 → T2 也行，但优先看下面
└─ 不能（需要对比、推导、多版式）
    ├─ 主体是「一道真题的完整求解过程」→ T3 真题长拆解档
    ├─ 主体是「论文里的图 / 题目原图」逐张讲 → T4 奶油论文图解档
    ├─ 主体是「赛事资讯」（赛程 / 报名 / 奖金 / 资格）→ T5 赛事资讯快报档
    └─ 其余（方法对比 / 对错辨析 / 评分细则 / 自查清单）→ T1 信息密度档
```

**时长校验**：
- 用户要 < 2 分钟 → T2（其他档撑不到那么短）
- 用户要 2–3 分钟 → T5 或 T1（压到 185s）
- 用户要 3–4 分钟 → T4
- 用户要 4–6 分钟 → T3

**一句话记忆**：**能不能用「编号 + 一句话」表达？能 → T2；不能 → T1。** 真题 → T3，图讲解 → T4，资讯 → T5。

## 三、混搭规则

用户说「T1 的配色 + T5 的版式」这类混搭时，**先确认三件事**：

1. **时长**：以版式多的那档为准（T5 的 10 版式撑不到 120s，会变成 180–200s）
2. **配色来源**：从哪档拿 `theme.ts`，另一档的 accent 语义色要重新映射（T1 是 8 色，T2 是 3 档语气，映射关系要先写出来给用户看）
3. **字幕模式**：混搭时只能选一种（句级 / 整段），不能一个视频里两种并存

混搭后要重新算字数预算，并明确告诉用户「这是第一次跑这个组合，版式间距可能需要一轮微调」。

## 四、新增档的门槛

要加第 7 档模板，必须满足：
1. 有一个**已交付**的真源项目（不能是设计稿）
2. 实测时长 / 帧数 / 场景数齐全
3. 能说清「和已有档的差异是什么」——差异小于 30% 就别开新档，做成已有档的变体

新档写完后，回到 `SKILL.md` 的模板索引表加一行。
